# HTML‐Web‐Pages  
A collection of static HTML & CSS projects showcasing web page designs for various tasks and applications.

## 🗂 Projects Included  
The repository contains the following folders, each representing a separate web page project:

- **Company Website** – A full multi‐frame website layout (navigation + content frames) for a company.  
- **E-Zoo** – A themed informational web page for a virtual zoo.  
- **Online Book Store** – A mockup site for browsing and buying books online.  
- **Online Quiz** – A simple interactive quiz web page implementation.  
- **Simple College Register Form** – A basic HTML registration form for a college.  
- **Web Tech – Online Study Platform** – A prototype page for an online education/study platform.

## 🛠 Tech Stack  
- HTML5  
- CSS3  
- Responsive design elements (where applicable)  
- No JavaScript frameworks or server‐side code — purely front‐end.
